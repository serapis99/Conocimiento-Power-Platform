# Niveles de desarrollo en Power Platform

Microsoft Power Platform permite desarrollar soluciones mediante herramientas de bajo código (*Low-Code*) y sin código (*No-Code*), facilitando la participación de personas con diferentes niveles de conocimientos técnicos.

Podemos clasificar didácticamente los perfiles de desarrollo en tres niveles, según su experiencia, conocimientos y capacidad para construir soluciones.

## 1. Citizen Developer (Desarrollador ciudadano)

Son personas que conocen profundamente los procesos del negocio, pero cuya especialización principal no necesariamente está relacionada con el desarrollo de software o la tecnología.

Utilizan herramientas intuitivas y visuales de Power Platform para crear aplicaciones, automatizaciones y soluciones que mejoran sus actividades laborales.

**Características:**

- Conocen los procesos y necesidades del negocio.
- Utilizan herramientas visuales y de bajo código.
- No necesitan conocimientos avanzados de programación.
- Pueden construir automatizaciones sencillas y aplicaciones funcionales.
- Buscan mejorar la productividad y reducir tareas repetitivas.

>[!example] **Ejemplo:** 
>un analista administrativo que utiliza Power Automate para automatizar el envío de reportes y notificaciones a partir de información almacenada en Excel.

## 2. Intermediate Developer (Desarrollador intermedio)

Es un perfil con conocimientos técnicos más desarrollados que puede construir automatizaciones y aplicaciones de mayor complejidad.

Comprende mejor el funcionamiento de los datos, las integraciones, las expresiones y la lógica de programación. Puede combinar las herramientas low-code con elementos de código cuando las necesidades de la solución lo requieren.

**Características:**

- Tiene conocimientos de lógica de programación.
- Utiliza expresiones avanzadas y estructuras de datos.
- Trabaja con JSON, API y diferentes fuentes de información.
- Construye automatizaciones con múltiples condiciones y procesos.
- Puede integrar código y servicios externos.
- Tiene mayor capacidad para diagnosticar errores y optimizar soluciones.

>[!example] **Ejemplo:** 
>un desarrollador que construye un flujo de Power Automate que consume una API, procesa respuestas JSON, transforma información y actualiza registros en diferentes aplicaciones.

## 3. Pro Developer (Desarrollador profesional)

Son profesionales con experiencia avanzada en desarrollo de software y conocimientos profundos de arquitectura, programación e integración de sistemas.

Su función es ampliar las capacidades de Power Platform mediante herramientas de desarrollo profesional, componentes personalizados e integraciones con otros servicios tecnológicos.

**Características:**

- Dominan lenguajes y herramientas de programación.
- Desarrollan conectores personalizados.
- Implementan integraciones complejas con servicios externos.
- Extienden las funcionalidades de Power Platform mediante código.
- Trabajan con arquitecturas, seguridad y administración de soluciones.
- Pueden implementar estrategias de desarrollo, pruebas y despliegue (ALM y DevOps).

>[!example] **Ejemplo:** 
>un desarrollador que implementa un conector personalizado, integra Power Platform con servicios empresariales mediante Azure y desarrolla componentes personalizados para Power Apps.

## 4. Comparación de los perfiles

| Característica | Citizen Developer | Intermediate Developer | Pro Developer |
|---|---|---|---|
| Conocimiento técnico | Básico | Intermedio | Avanzado |
| Programación | No necesaria | Conocimientos básicos o intermedios | Dominio profesional |
| Herramientas | Low-Code / No-Code | Low-Code y código | Low-Code y desarrollo tradicional |
| Complejidad | Sencilla | Media o alta | Alta o empresarial |
| Integraciones | Conectores disponibles | API y expresiones | Integraciones personalizadas |
| Enfoque | Productividad del negocio | Automatización avanzada | Extensión y arquitectura de soluciones |

> [!important] Consideración
> Estos perfiles representan una clasificación orientativa de habilidades, no una jerarquía oficial de certificaciones de Microsoft. Una persona puede desarrollar habilidades de distintos perfiles dependiendo de su experiencia y especialización.

La Power Platform busca facilitar la colaboración entre usuarios de negocio, desarrolladores y profesionales de TI para construir soluciones que combinen las capacidades low-code con el desarrollo tradicional.
