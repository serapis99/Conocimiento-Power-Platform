## Personalizar la barra de tareas de Power Automate

Durante el aprendizaje y desarrollo de automatizaciones, podemos personalizar la barra de tareas o panel de herramientas para tener accesos rápidos a las funcionalidades que utilizamos frecuentemente.

Por ejemplo, podemos anclar la opción Conexiones (Connections), ya que la utilizaremos recurrentemente para conectar Power Automate con diferentes herramientas, aplicaciones y servicios.

### ¿Cómo hacerlo?

1. Ubicar la barra de tareas o panel de opciones. 
2. Seleccionar la opción Más (More).
3. Se desplegarán opciones que podemos activar o desactivar.
4. Marcar las opciones que queremos mantener visibles o ancladas.
5. Activar Conexiones (Connections) para tener acceso rápido a ellas.
    

**Objetivo**: personalizar el entorno de trabajo para facilitar el acceso a las herramientas que utilizamos con mayor frecuencia y mejorar nuestro flujo de trabajo.
